# DEVO+ Roadmap

Документ перечисляет все запрошенные функции и в какой фазе они появятся.
Фаза 1 (этот PR) реализует фундамент. Каждая следующая фаза — отдельный PR.

## Фаза 1 — Foundation (этот PR)

- [x] Монорепозиторий `api/` + `web/`
- [x] Дизайн-система: Nunito логотип, Inter тело, glassmorphism utilities,
  светлая/тёмная/системная тема
- [x] Главный экран как на референсе: логотип DEVO+, поиск-овал, кнопка ⋮,
  карточки чатов с аватаром, превью и временем
- [x] Тени-затемнения сверху и снизу списка чатов (`.scroll-fade-y`)
- [x] Меню по нажатию на ⋮ (новый чат, поиск, уведомления, обои, профиль, выход)
- [x] Страница профиля с share-link
- [x] Заглушка экрана чата
- [x] Login через Google OAuth (id_token + серверная проверка)
- [x] Cloudflare Turnstile в форме входа (опционально)
- [x] Endpoint `/auth/google`, `/me`, `/chats`, `/config`, `/healthz`
- [x] WebSocket `/ws/chat/{id}` (in-memory брокер комнат)
- [x] При первом входе автоматически создается чат «Избранное»
- [x] Cloudflared конфиг + инструкции

## Фаза 2 — 1-на-1 чаты

- [ ] Полный экран чата (список сообщений, ввод, отправка)
- [ ] Реакции, ответы (reply), пересылка, редактирование, удаление у себя/у всех
- [ ] Прочитано / доставлено (галочки)
- [ ] Статус «онлайн / печатает / был(а) только что в HH:MM»
- [ ] При листании показывать дату-разделитель
- [ ] Кнопка «↓» для перехода к последнему сообщению
- [ ] Звук отправки (с настройкой mute)
- [ ] Контекстное меню чата (закрепить, очистить, архив, удалить)
- [ ] Поиск по сообщениям внутри чата

## Фаза 3 — Медиа

- [ ] Фото, видео, голосовые, документы — с подписью и предпросмотром
- [ ] Inline crop фото (выделение области)
- [ ] Inline trim видео
- [ ] Хранилище через R2 (или локальный диск как fallback)
- [ ] Превью видео/аудио прямо в композере

## Фаза 4 — Группы / каналы / сообщества

- [ ] Создание группы / канала / сообщества
- [ ] Роли: owner / admin / member
- [ ] Продвинутые права админов:
  - [ ] Запрет на удаление сообщений для обычных участников
  - [ ] Исчезающие сообщения (1 час … 7 дней)
- [ ] Lobby Mode: модератор подтверждает вход
- [ ] Лог действий админов (кто что изменил/удалил)

## Фаза 5 — Поиск, опросы, география, обои

- [ ] Глобальный поиск (пользователи + каналы)
- [ ] Поделиться профилем по ссылке (`/u/<username>`)
- [ ] Опросы (poll messages)
- [ ] Геолокация (постоянная и **разовая, самоуничтожающаяся через 5 мин**)
- [ ] Обои чата (preset + загрузка своих)
- [ ] Обои для главного экрана приложения

## Фаза 6 — Звонки и Audio Rooms

- [ ] Видео/аудио-звонки через **Jitsi Meet iframe API** (`meet.jit.si`)
- [ ] Audio Rooms (Twitter Spaces / Telegram-like): только голос,
  поднятие руки, несколько модераторов

## Фаза 7 — Безопасность и приватность

- [ ] Stealth-режим: онлайн не светится, последний визит скрыт
- [ ] Точное «Был в HH:MM» когда пользователь не в Stealth
- [ ] Cloudflare Turnstile + опциональная WAF-интеграция
  (скоринг 1–99, капча для подозрительных, блокировка ботов)
- [ ] Backup-токены / rotation для JWT secret

## Фаза 8 — Polish

- [ ] PWA-установка
- [ ] Уведомления (push)
- [ ] Архив, закреплённые чаты
- [ ] Полные настройки уведомлений
- [ ] Тесты (pytest + vitest), E2E (Playwright)
